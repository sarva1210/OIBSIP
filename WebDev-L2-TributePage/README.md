# Legends Who Inspired Us
A responsive tribute website created as part of the OASIS INFOBYTE Web Development & Designing Internship — Level 2, Task 2.

The website presents four inspiring personalities. Users can select a person from the home page and view their biography, timeline, achievements, and a quote without leaving the main HTML page.

## Featured Personalities

- A. P. J. Abdul Kalam
- Swami Vivekananda
- Ratan Tata
- Dr. B. R. Ambedkar

## Features

- Clean and responsive landing page
- Four personality cards with images
- Clickable cards and tribute buttons
- Dynamic tribute sections using JavaScript
- Biography section with multiple paragraphs
- Timeline of important events
- Key achievements section
- Quote section
- Back to Legends navigation
- Responsive layout for desktop, tablet, and mobile
- Images stored separately in the assets folder
- No separate HTML page required for each personality

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

# How It Works
1.The home page displays cards for four personalities.
2.Click on a card, image, name, or View Tribute button.
3.JavaScript loads the selected person's information.
4.The tribute view displays:
    ~Biography
    ~Timeline
    ~Key achievements
    ~Quote
5.Click Back to Legends to return to the home page.
