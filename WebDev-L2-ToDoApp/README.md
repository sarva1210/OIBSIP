# To-Do Web App
A responsive and interactive To-Do Web App created as part of the OASIS INFOBYTE Web Development & Designing Internship — Level 2, Task 3.

The application allows users to create, manage, edit, complete, and delete daily tasks. Tasks are organised into separate Pending Tasks and Completed Tasks lists.

## Features

- Add new tasks using the input field and Add Task button
- Newly added tasks appear in the Pending Tasks list
- Mark tasks as completed using the completion toggle
- Completed tasks automatically move to the Completed Tasks list
- Edit task text inline
- Delete tasks permanently
- Pending task count indicator
- Completed task count indicator
- Timestamp showing when a task was added
- Timestamp showing when a task was completed
- Empty-state messages for both lists
- Tasks persist across page refreshes using localStorage
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage
