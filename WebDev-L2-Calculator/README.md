# calculator
A fully functional and responsive calculator built using **HTML5, CSS3, and Vanilla JavaScript** as part of the **OASIS INFOBYTE Web Development & Designing Internship – Level 2**.


# Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Percentage operation
- Decimal number support
- Full expression display
- Operator chaining
- Clear (`AC`) functionality
- Delete (`DEL`) functionality
- Division-by-zero error handling
- Calculation history
- History stored using Local Storage
- Clear history functionality
- Responsive design
- Keyboard support
- Interactive buttons using JavaScript event listeners
- Calculation logic implemented without using `eval()`
